# Changelog

## 0.1.2 (2026-07-09)

- Rebranded the Python agent codebase from `OpenPlanter` to `Quantico`.
- Removed the deprecated `openplanter-agent` console script alias.
- Updated session/config directories, user agent strings, prompts, and TUI art.

## 0.1.1 (2026-07-09)

- Rebranded the desktop bundle from `OpenPlanter` to `Quantico`.
- Updated Tauri `productName`, `identifier`, window title, and bundle version to `0.1.1`.

## 0.1.0 (2026-07-09)

First tagged release of Quantico AI Agency.

- Rebranded fork from OpenPlanter to Quantico AI Agency.
- Updated CLI entry point to `quantico-agent` with `openplanter-agent` alias.
- Added optional `textual` and `test` dependencies.
- Fixed local test suite for non-live runs (`SKIP_LIVE_TESTS=1`).
- Added desktop build workflows for Linux, macOS, and Windows.
