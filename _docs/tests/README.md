## Overview

This directory contains unit tests focused on validating data fetchers used elsewhere in the repository. At the root there are two test modules: test_fetch_census_acs.py which holds unit tests for the Census ACS fetcher, and test_fetch_fec.py which contains unit tests for the FEC (Federal Election Commission) data fetcher implemented in scripts/fetch_fec. The files exercise the fetching logic and act as regression checks to ensure data retrieval behavior remains correct as the codebase evolves.

Together these tests form the verification layer for the fetcher scripts: they are designed to be run as part of a test suite to detect regressions in the data-fetching functionality. The directory plays the role of a focused test pack within the docs/tests area of the repository, giving developers quick insight into how the Census ACS and FEC fetchers are expected to behave and providing concrete examples of expected inputs and outputs for those components. There are no subdirectories listed here; the structure is flat and limited to the two test files described.


### File Organization

The directory is organized as a flat collection of test modules, one per target fetcher. Each file is named to clearly indicate the module under test: test_fetch_census_acs.py for the Census ACS fetcher and test_fetch_fec.py for the FEC fetcher implementation in scripts/fetch_fec. This keeps test discovery simple and aligns file names with the components they validate.
