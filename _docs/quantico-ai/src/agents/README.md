## Overview

This directory holds TypeScript agent implementations and a barrel export that together define the agent layer of the system. At the root there is a BaseAgent implementation (base-agent.ts) that provides shared behavior and role/identity-related types and constants; concrete agent modules (digital-sleuth.ts, forensic-accountant.ts, recon-specialist.ts, director.ts) import and extend that base to implement role-specific logic. The index.ts file is a central re-export barrel that aggregates agent symbols for external consumers.

Together these files form a compact, feature-focused collection: base-agent.ts is the foundational piece other agents depend on, the individual agent modules encapsulate role-specific responsibilities and task/message types, and index.ts provides the canonical entry point for other parts of the codebase to import agents and their types. There are no subdirectories listed for this directory; the organization is intentionally flat to keep agent implementations and their shared base colocated for ease of navigation and maintenance.


### File Organization

Files are organized in a flat layout: a single foundational implementation (base-agent.ts), multiple concrete agent modules that import and extend the base, and a barrel file (index.ts) that re-exports key symbols. This keeps related agent code together and makes the barrel an obvious single import point for external modules.
