## Overview

This directory contains small, focused TypeScript modules that define core types used by the Quantico-AI codebase. At the root level there are two files: gateway.ts provides a set of lightweight, clean-room gateway types used to represent gateway-related data and contracts; roles.ts defines role-related types and an explicit role hierarchy for the system. Both modules are type-definition focused and intended to be imported by other parts of the project that require those typed contracts.

Together these files establish a predictable, centralized type surface for gateway and role concepts. The gateway types encapsulate the shapes and expectations for gateway interactions while the roles definitions centralize role names, structures, and hierarchy rules. By keeping these concerns in a single directory, the project enforces consistency across modules that implement gateway logic or access-control checks and makes it straightforward to find and update the canonical type definitions when system-wide changes are required.


### File Organization

Files are organized flatly at the directory root, each file representing a distinct type domain (gateway and roles). This keeps type concerns separated and discoverable: one file per conceptual type group so consumers import only what they need.
