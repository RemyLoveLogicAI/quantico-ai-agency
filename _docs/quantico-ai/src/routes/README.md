## Overview

This directory contains the route modules that expose the application's agent-related endpoints and health-check endpoints. At the root level there are two TypeScript source files: agents.ts, which provides the routing logic for agent-related operations, and health.ts, which contains the endpoints used for application health checks and related diagnostics. Each file is a focused route module responsible for registering one area of the HTTP surface for the application.

Together these modules form the minimal routing surface documented in this directory: health.ts is used to report application health and readiness, while agents.ts groups the endpoints that manage or interact with agents. The files are intended to be imported by a higher-level router or server bootstrap code (not shown here) to assemble the full set of routes for the running application. This directory is therefore the place to find and modify HTTP route definitions for health and agent features within the system.


### File Organization

Files are organized flat at the directory root, with each TypeScript file representing a single route module focused on a specific functional area (agents, health). This keeps route concerns separated and easy to locate.
