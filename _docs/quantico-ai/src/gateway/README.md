## Overview

This directory hosts two TypeScript modules that together implement parts of a gateway for the clean-room feature. The clean-room.ts module brings in the Hono web framework, an authentication middleware, and gateway-related TypeScript types; it serves as the gateway composition point where routing/middleware and request handling are composed. The zo-connector.ts module implements a connector piece used by the gateway (its specific responsibilities are in the file), providing integration logic referenced by gateway code.

Together these modules form a small, focused gateway layer: clean-room.ts is the entry point that composes framework-level routing and middleware with gateway types and authentication, while zo-connector.ts provides connector-level functionality used by that gateway. There are no subdirectories listed under this directory; the organization is flat and focused on gateway concerns related to the clean-room feature and its external connector integration.


### File Organization

Files are organized at the directory root as discrete modules: one composition/entry module (clean-room.ts) that wires Hono, authentication middleware, and gateway types, and one connector module (zo-connector.ts) that encapsulates external integration logic for the gateway.
