## Overview

This directory contains the startup entrypoint for the Quantico-AI Agency gateway and two focused subdirectories that hold the gateway's default configuration and application entry point code. At the root level there is a single shell script, start.sh, which acts as a simple startup entrypoint for launching or orchestrating the Quantico-AI gateway process. That script is intended to be the initial invocation point when the gateway is started in development or deployment environments.

The config/ subdirectory contains TypeScript module(s) (notably defaults.ts) that provide baseline configuration values and constants used throughout the gateway. The src/ subdirectory contains the TypeScript application entry point (index.ts) plus grouped implementation layers that wire HTTP routing, authentication middleware, agent implementations, and type definitions for the clean-room gateway feature. Together these components provide a cohesive bootstrapping flow: start.sh triggers the running process, src composes the server and runtime behavior, and config supplies default values other parts import and rely upon. This directory therefore serves as the local gateway surface for launching and configuring the Quantico-AI service within the larger system.


### File Organization

Files are organized with a single lightweight root-level entry script (start.sh) that boots the gateway, while implementation code and configuration are separated into dedicated subdirectories: config/ for default configuration modules and src/ for the application entry point and implementation layers. This keeps startup orchestration distinct from application code and defaults.

## Architecture Notes

- Startup, configuration, and implementation are separated: start.sh (entrypoint) at the root, config/ for defaults, and src/ for application wiring and agent implementations.
- The src/ directory is the implementation layer that composes HTTP routing, authentication middleware, and agent logic; config/ provides centralized default values so runtime behavior can be adjusted without changing bootstrap code.
