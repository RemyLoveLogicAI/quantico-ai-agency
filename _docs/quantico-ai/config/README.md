## Overview

This directory contains TypeScript module(s) that provide the default configuration values for the Quantico AI gateway. At the root level there is a single file, defaults.ts, which defines baseline configuration settings that other parts of the gateway import and rely upon. The contents are intended to centralize default values so runtime components can import and override them as needed.

Because there are no subdirectories, the directory is flat and focused solely on configuration defaults. The module(s) here play a supporting role in the larger system by defining canonical default values; other modules import these values to ensure consistent behavior across the gateway. Developers making configuration changes should update this file to keep defaults consistent project-wide, and any runtime or environment-specific overrides should be implemented elsewhere in the system where configuration layering is performed.
